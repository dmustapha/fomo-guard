**What This Becomes:** The personal finance guardian for every crypto-native shopper.
**The Risk:** Judges see it as anti-Purch. Mitigation: frame as "smart Purch, not no Purch" — user still buys, just smarter.
**Why this wins:** MOST MEMORABLE. Zero precedent in Vault. Deep product API integration (searches for alternatives). Speaks to real crypto-native behavior. Demo is a clear before/after moment.
